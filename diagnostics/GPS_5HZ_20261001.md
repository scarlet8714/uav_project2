# GPS 5 Hz 實機測試

- 時長：300.1 秒；GPS 裝置：`/dev/serial/by-id/usb-1a86_USB_Serial-if00-port0`。
- 啟動時傳送 UBX CFG-RATE，測量週期設為 200 ms；9600 baud 下僅保留 RMC、VTG 輸出。
- 收到 RMC 1499 筆、VTG 1499 筆；RMC 平均 5.000 Hz，中位間隔 200.0 ms，最長間隔 201.5 ms。
- NMEA 解析或 checksum 錯誤 0 筆；另有 1 筆非 NMEA 資料，未保存內容，不能確認是否為設定回覆。
- RMC 1499 筆均為無效定位，故本次只驗證輸出頻率與串口穩定性，未驗證座標精度。天線需要可見天空並取得 fix 後才能驗證定位。
