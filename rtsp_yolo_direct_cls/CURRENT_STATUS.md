# 三類偵測與軍車細分類版本

2026-10-13 從目前工作目錄的 `rtsp_yolo_direct` 完整複製而來，
原資料夾未修改。所有媒體、ICE、WebSocket、GPS 與看門狗功能沿用。

新增：

- 預設 `test3.engine` 三類偵測及 `classifier_fp16.engine` 軍車細分類。
- 使用者指定分類順序：0 cm34、1 light_tactical、2 medium_tactical。
- 原生 TensorRT 分類載入與 engine 未就緒時的三類偵測運作。
- 每個 ID 預設最近 7 次實際分類的等權重多數決，平票優先保留目前的並列最高票類別；不足 7 次時使用已有結果，第一次即顯示分類。
- 預設 legacy 的運動／尺寸預測只供內部配對使用，ID 保留 0.5 秒。
- ByteTrack 可選，沿用其 ID 並增加同樣的內部時間保留。
- 移除漏檢時補出的預測框，僅顯示實際偵測框，前端版本 `20261013.cls.4`。
- 前端也忽略舊版傳來的預測框，來源重置時清除追蹤／分類。
- 漏檢期間不顯示補框、不重新分類或更新 GPS，但分類紀錄保留供 ID 接回。

分類 engine 已完成，已驗證 Jetson GPU 載入與推論，實際輸入 FP32
`images [1,3,224,224]`，輸出 FP32 `logits [1,3]`。
三組合成影像的最高分類別與 ONNX 一致，機率最大差異約 0.0169；
0.01 的初始嚴格門檻未通過，ONNX 官方參考執行器已複查。

尚待實機確認：影像前處理與實際分類索引是否吻合訓練設定、
真實影像的分類準確率、實際車輛交錯及漏檢的追蹤品質。
目前 RGB／224 直接縮放／ImageNet 正規化為待核對的初始設定。

驗證：77 項 Python 測試、34 項前端測試通過，語法編譯通過；
已比對來源資料夾檔案雜湊，確認原版未被本次修改。
